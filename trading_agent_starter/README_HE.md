# Trading Agent Foundation — Alpaca Paper + Historical Data

## המצב הנוכחי

חיבור Alpaca Paper לקריאה בלבד עבר בהצלחה במחשב המקומי, לפי דיווח בעל הפרויקט.
נוסף שלב A: הורדת נרות היסטוריים של 30 דקות למספר נכסים, עם בדיקת שלמות הנתונים,
UTC, ימי מסחר וסגירות מוקדמות, מניעת שימוש בנרות שעדיין לא הושלמו ודוח חוסרים.
ההורדה האמיתית של הנתונים החדשים עדיין טעונה אימות מקומי.

הפקודות, חוזה הנתונים ותנאי המעבר לשלב הבא נמצאים ב־[MARKET_DATA_CONTRACT.md](MARKET_DATA_CONTRACT.md).
הגדרת Alpaca הקיימת נמצאת ב־[ALPACA_PAPER_SETUP_HE.md](ALPACA_PAPER_SETUP_HE.md).
לא נוספה שליחת פקודות, ולא הופעל מסחר. קוד IBKR וההדגמה היומית המקוריים נשמרו.

## תיעוד התשתית המקורית — Foundation 0.1

עודכן ונבדק ב־14 בספטמבר 2026. מיועד למסחר מישראל בשוק האמריקאי דרך IBKR.

זוהי חבילת התשתית הראשונה בדרך לסוכן מסחר אוטונומי. היא כוללת קוד רץ למחקר בסיסי, רכיבי בדיקת סיכון, מניעת כפילויות מקומית, ובדיקת חיבור לקריאה בלבד ל־IBKR Paper. היא עדיין אינה סוכן שמבצע עסקאות אצל הברוקר ואינה אסטרטגיה שהוכחה כרווחית.

פתחו את `Trading_Agent_Setup_HE.html` למדריך המלא: חשבונות, הורדות, סדר ההתקנה, תוכנית הפיתוח ותנאי המעבר בין השלבים.

למסגרת המעודכנת קראו גם `GAP_ANALYSIS_V1_HE.md` ו־`TECHNICAL_SPEC_V1_HE.md`. ה־Gap Analysis מסביר מה נשמר ומה חסר; ה־Technical Specification מגדיר את Phase 0, Phase 1, baseline, data, schema, risk ו־AI evaluation.

## התחלה ב־Windows

1. התקינו Python 3.13 בגרסת 64 ביט מהאתר הרשמי, כולל Python Launcher.
2. חלצו את החבילה לתיקייה קבועה כגון `C:\TradingAgent`.
3. הפעילו `setup_windows.bat`. ההתקנה יוצרת סביבה מקומית וקובץ הגדרות, ומריצה 21 בדיקות.
4. הפעילו `run_demo.bat`. זו הדגמה על נתונים מלאכותיים; אין צורך בברוקר, באינטרנט או במנוי נתונים.
5. רק לאחר התקנת TWS וה־SDK הרשמי והתחברות ל־Paper, עדכנו את `config/ibkr.local.json` והפעילו `check_connection.bat`.

הצעד המדויק לחיבור Paper: התחברו ל־TWS Paper, הפעילו `Global Configuration → API → Settings → Enable ActiveX and Socket Clients`, השאירו בשלב זה `Read-Only API` מסומן, ודאו יציאה `7497` ו־localhost בלבד. לאחר התקנת ה־SDK הרשמי, העתיקו את `config/ibkr.example.json` ל־`config/ibkr.local.json`, הכניסו רק את מספר חשבון ה־Paper מסוג `DU...`, והפעילו `check_connection.bat`. אין לשמור סיסמה או MFA בקובץ.

## פקודות למפתחים

קוד הבסיס דורש Python 3.11 ומעלה; נבדק כאן על Python 3.12.14 ב־Linux. קובצי BAT והאינטגרציה עם TWS עדיין לא נבדקו על מחשב Windows אמיתי.

```bash
python3 -m unittest discover -s tests -v
python3 -m agent demo
python3 -m agent probe --config config/ibkr.local.json
python3 -m agent history --config config/ibkr.local.json --output runs/history
python3 -m agent research --csv runs/history/SPY_daily.csv
```

ב־Windows החליפו את `python3` ב־`.\.venv\Scripts\python.exe`. הבסיס והבדיקות משתמשים רק בספרייה הסטנדרטית. `probe` ו־`history` דורשים בנפרד את `ibapi` מההורדה הרשמית של IBKR; קוד הספק אינו מצורף.

## מה הקוד עושה

| רכיב | התנהגות בפועל |
|---|---|
| `agent/replay.py` | אסטרטגיית ייחוס של ממוצעים נעים על נכס אחד, עם החלטה בסגירה וביצוע מדומה בפתיחת הנר הבא; קנייה בלבד ויציאה למזומן |
| `agent/risk.py` | פונקציית בדיקות מקדימות למחיר, טריות נתונים, מזומן, חשיפה כולל קניות ממתינות, וכמות זמינה למכירה |
| `agent/ledger.py` | SQLite עם מזהי כוונות ייחודיים ומצב עצירה שנשמר לאחר סגירת התהליך |
| `agent/ibkr_readonly.py` | בדיקת חשבון Paper מדויק, קבלת סיכום חשבון וספירת פוזיציות/פקודות פתוחות; הורדת נרות יומיים אופציונלית |
| `tests/` | בדיקות חסימה, נתונים פגומים, כפילויות לאחר הפעלה מחדש, עלויות והיעדר השפעת העתיד על החלטות עבר |

רכיבי הסיכון והיומן הם יחידות יסוד נבדקות; הם טרם חוברו למנוע ביצוע אצל הברוקר. בדיקת snapshot חד־פעמית אינה reconciliation רציף. אין כאן מנהל שירות 24/7, מודל ML מאומן, אימון walk-forward מלא, התראות חיצוניות או מעבר ל־Live.

## פירוש הדוח

`research_report.json` כולל אסטרטגיה, ייחוס קנייה והחזקה באותה הקצאה התחלתית של 20%, מזומן בריבית אפס, ותרחיש הכפלת עלות הביצוע המשוערת. לייחוס הקנייה והחזקה אין עצירת drawdown, ולכן יש לבדוק הבדלי סיכון וחשיפה לפני מסקנה. אין אופטימיזציית פרמטרים או אימון בדוגמה זו.

העמלה בדוגמה היא דולר לפעולת מילוי, ובנוסף 10 נקודות בסיס של מחיר פחות נוח לכל צד. אלה הנחות הדגמה, לא מחירון IBKR. פוזיציות אחרונות משוערכות ולא נמכרות בסוף. אין חשבונאות דיבידנדים, מס, ריבית מזומן, סליקה או תור פקודות. הבדיקה הראשונית אינה מתאימה לאישור רווחיות או כשירות חשבון Cash.

נתוני `history` הם נרות `TRADES` יומיים בשעות הרגילות מהברוקר. הנר של היום מוסר כדי לא להשתמש בנר שעדיין מתהווה. אין להשתמש בנתונים אלו כאילו היו מאגר point-in-time או סדרת תשואה כוללת שנבדקה. אין להפיץ נתוני שוק בניגוד לרישיון הספק.

## פרטיות ומצב החיבור

סיסמה ואימות דו־שלבי נשארים ב־TWS. בקובץ המקומי מופיע מספר חשבון Paper בלבד. אל תשתפו את קובץ ההגדרות, צילומי החשבון או יומני TWS ללא בדיקה. הדוח המצומצם משמיט יתרות ומספרי חשבון מוכרים מתוך הודעות שגיאה, אך עדיין יש לעיין בו לפני שיתוף.

יציאות החיבור המותרות הן ברירות המחדל ל־Paper בלבד: TWS‏ 7497 ו־IB Gateway‏ 4002, דרך `127.0.0.1`. נדרשת התאמה לחשבון `DU` המדויק. יציאה לבדה אינה הוכחה למצב Paper. תמיכה בחשבון בעל תבנית אחרת דורשת בדיקה מפורשת, ולא הסרת החסימה.

אין נתיב ביצוע Live בחבילה. לא נשלחו עסקאות ולא נרכשו שירותים בעת הכנתה.
