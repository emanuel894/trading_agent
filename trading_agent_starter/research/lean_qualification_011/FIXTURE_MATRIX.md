# Exact synthetic contract matrix

**Design only: none of Q01–Q33 has been implemented or executed against LEAN.**
Each listed variant is mandatory. No production data or actual security is used.
Use separate clean runs per row/variant unless a row explicitly describes a
sequence. Compare exported business records against these independent oracles.

## Shared definitions

- `D=2025-01-06T15:00:00.000000000Z`, an open RTH synthetic session;
  int64 UTC nanoseconds are authoritative. Calendar fixtures explicitly encode
  New York timezone, sessions and close; they are not provider calendars.
- Instruments `I1` (issuer `U1`, class `A`, listing `L1`, ticker `AAA`, USD,
  NYSE), `I2` (`U2/B/L2/BBB`, Nasdaq), `I3` (`U1/B/L3/AAB`, NYSE). All identity
  intervals contain D, unless overridden. Evidence IDs `E-*` reference frozen
  synthetic bytes with hashes and `capture_mode=fixture`. No issuer is FMBH.
- For ordinary end-to-end entry fixtures: cash/NAV $10,000, flat portfolio,
  volatility `sigma5=0.05`, target cap `min(0.10 NAV,0.0025 NAV/sigma5)=$500`,
  five-position limit, gross 60%, long only, no halt. A five-share test **intent**
  is already frozen for fill mechanics; end-to-end sizing must instead floor
  quantity using executable price plus fee reserve (Q23). No implicit resizing
  of a frozen fill-mechanics intent. Seeded holdings/cash below are initial
  conditions, not orders that bypass risk checks.
- `q0`: I1 at `D-0.5s`, bid 99.99, ask 100.00, bid/ask sizes 1000 **shares**;
  `q1`: I1 at `D+1s`, bid 100.00, ask 100.02, sizes 1000 shares. Both are SIP
  fixture quotes, conditions exactly `[R]`, exchanges/tape recorded, gap=false,
  status known TRADABLE; available time equals event time using explicitly
  **simulated** availability. Separate receipt is null. A prospective variant
  has an explicit receipt time and must use it. No quote is fill-forwarded.
- Decision snapshot: available at D, age ≤2s, positive bid < ask,
  spread `10000*(ask-bid)/((ask+bid)/2) ≤20bps`, R-only allowlist, known tradable
  RTH status, no gaps, verified positive share units. Entry fill: first valid
  available quote in **inclusive `[D+1s,D+5s]`**, also age ≤2s at availability;
  buy ask ×1.0005, sell bid ×0.9995; stress multiplier 1.001/0.999. Reject a
  frozen order exceeding 10% displayed same-side shares; no clipping to save it.
- Exact decimal arithmetic before venue rounding; this synthetic venue permits
  decimal USD accounting with no rounding, integer trade shares. Real venue
  tick/fee rounding requires a later explicitly versioned input, not inference.
- Fee per filled order-side: `max($1, verified applicable cumulative fee)`;
  incremental charges equal the increase in that cumulative amount. No fee for
  an unfilled canceled/rejected order. This fragmentation convention is a
  qualification scenario, not a new broker fee schedule or research amendment;
  production partial-fill applicability must be reviewed before real evaluation.
- Gross/symbol exposure uses holdings plus all remaining entry quantities at
  reserved adverse price; pending sells do not reduce it. Cash reservation
  includes worst permitted fill price and fee upper bound. If no bound exists,
  block entry. Exits reserve shares and never create a short. Policy fixtures
  state their prices/reservations explicitly to avoid mixing sizing with fills.
- Every oracle includes input/evidence refs and stable research identity. No
  row may create a real order, provider/model request, population admission or
  scientific metric. Missing terminal value is null, not zero return.

## Interpretation

Fixture isolation is deliberate: fill/fee/policy primitives test exact semantics
without treating an otherwise oversize test order as an admitted portfolio trade.
End-to-end runs combine the same gates and must never permit such a bypass.
The ordinary backtesting path must run Q01–Q18 and end-to-end policy cases;
fake-destination Q19/Q28–Q31 test boundary logic only, not actual plugin behavior.
Q27 applies to both streams. Document per-variant results; an unrun/unsupported
variant is not a pass. Production partial fills, actual action economics and
broker reconnect behavior remain separate admitted-data/execution-host gates.
