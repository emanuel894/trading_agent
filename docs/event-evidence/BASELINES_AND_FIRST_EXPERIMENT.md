# Cheap controls and the first separate experiment

These are requirements for **future registrations**, not new registered arms,
dates or permission to evaluate returns. All arms must share the same admitted
versions, event inventory, as-of links, opportunities, deadlines, forecasting
family, tuning budget, execution assumptions and cost accounting. An LLM is
optional and removable; its output cannot create events, identity or source truth.

## Minimum non-LLM controls by family

Every family needs a market-only control (trailing price/volume/volatility and
market response already visible at decision), a scheduled-event/event-type
indicator where applicable, and simple predeclared reaction/momentum and reversal
references using only prices already available. These are candidate controls to
freeze, not a search through whichever rule wins on a test. A release-time
reaction window ending after the actual decision is a label, never an input.

| Family | Required cheap controls before any LLM challenger | Optional incremental extraction question |
| --- | --- | --- |
| Fed decision/statement | Calendar/meeting indicators; announced target range and change from prior **admissible** setting; balance-sheet-policy markers; deterministic token/term/negation counts and diff against prior statement; predecision market response. Surprise only against a legally available frozen expectations snapshot with its own cutoff. | Does bounded source-spanned language extraction add information beyond the numbers, text changes and already observed market response? |
| Fed minutes | Meeting-to-publication gap, deterministic topics/term changes, vote/dissent counts and references to policy trajectory; prior statement already public at minutes release as context. | Does additional structured language improve on these counts/diffs? Never treat minutes as known at meeting time. |
| Speeches/testimony | Scheduled versus unscheduled, speaker/role as-of, prepared-text type, fixed policy terms, numeric/rate references and change from prior comparable speech; missing delivery/Q&A flags. | Can constrained extraction improve on fixed terms without knowledge from later Q&A/transcripts? |
| CPI/PPI/employment/GDP/other scheduled macro | Release/calendar type; released level/change versus last admissible prior; prior as printed versus prior previously known; revision magnitude; SA/NSA/base-year/estimate-stage indicators. Consensus surprise only if pre-release, licensed snapshots exist. | Is narrative interpretation useful after the numeric and revision vector? Missing consensus must be explicit for all arms. |
| Later macro revisions/corrections | New-minus-previous **same-series/unit/definition** vintage; correction-type/benchmark/seasonal flags and age of affected period. Keep new-period change separate from revision to old periods. | Does narrative cause/scope add information beyond revision size and type? |
| Rules/regulations/notices | Agency/type/proposed-versus-final indicators; comment/effective/compliance delays; deterministic CFR/docket/RIN, dates, dollar thresholds and obligation/exception terms; then-known affected sectors. | Can source-grounded extraction of obligations/exemptions add beyond structured fields and terms? |
| Tariffs/trade controls | Rate delta, covered classification/country and then-known exposure; effective/entry-window delay, exemptions/extensions, fixed action terms. | Does bounded annex/exception extraction add beyond rates, scope and effective windows? No geopolitical forecast. |
| Sanctions | Addition/change/removal/general-license indicator, list/program/subject type, deterministic entity IDs and effective-window features; then-known exposure. | Does source-spanned scope/exception extraction add beyond formal list changes? |
| Government awards | Award/modification/deobligation type; obligation delta versus ceiling/options; duration; agency/recipient identifiers; amount relative to then-known revenue/backlog only when supported; public-announcement lag/missing flags. | Does text clarify material economics beyond amount, recipient and terms? No invented parent revenue allocation. |
| Issuer releases/earnings/guidance | Numeric actual/prior, properly licensed expectations, guidance-range change, deterministic text changes, fiscal period and prior-disclosure/market response controls. | Does narrative add incremental information under the shared envelope? This issue does not change existing 10-Q A/B/C/N. |
| News | Admissible story counts/topic and numeric-fact indicators, fixed lexicon polarity/negation, novelty versus then-known text, update/retraction flags, duplicate-normalized counts, source/latency indicators. | Do verified event/fact extractions improve over cheap text on identical content? Editorial explanations of a move are post-move evidence, not earlier predictors. |

Numeric surprise is `released value - pre-release consensus` with units and
version checks; optional scaling uses training-only dispersion, never a later
revised consensus. Release-vs-prior and revision features do not require consensus
and remain mandatory when surprise cannot be lawfully obtained. No paid consensus
or expectations call is authorized here. No LLM may fill missing expectations.

Fit transforms/dictionaries/topic models and select controls on chronological
training/validation only; freeze code, vocabulary, feature windows and thresholds.
Optional TF-IDF/regularized text models can challenge lexicons if separately
budgeted. Record all trials/failures. Group related publications and revisions to
avoid treating one economic episode as independent samples. Keep an untouched
test, purge overlapping labels, charge data/compute/latency/failure costs, and
allow abstentions/failed extraction to lose on the common denominator.

## First separately registered experiment proposal

**Recommend one prospective FOMC statement family, one predeclared broad market
instrument, and no issuer/exposure graph.** Use only scheduled decision statements;
exclude minutes, speeches, press conferences, projections and unscheduled decisions
from this first scope by a definition frozen before capture. Capture exclusions
for coverage, rather than selecting announcements by how much the market moved.
SPY is the proposed instrument subject to the later source/actionability gate;
it is not inserted into the existing operating-company universe or current
candidate ledger. No new instrument eligibility is asserted here.

This choice has a compact official document and strong numeric/text controls,
with a bounded optional extraction task. A broad all-government/news study would
add rights, identity and coverage dependencies before the simplest question is
answerable. The small number of FOMC decisions means any short pilot is a
feasibility study, not a credible alpha confirmation.

The **first separately registered pilot** should take the first eight consecutive
scheduled statements after an explicitly approved future capture start. Its
primary measurement is the fraction of predeclared releases with qualified
original bytes, clocks, verified facts and cheap controls ready by a common
deadline; report all eight, all outages, corrections, late stages and costs.
Report deterministic rate/number extraction against source-spanned adjudication
and prove that future corrections do not change frozen past bundles. It must not
make an incremental-alpha or profitability claim. This is the smallest useful
pipeline experiment before paying for extraction or expanding event families.
The number eight is a proposal requiring its own registration, not a change to
any existing sample size.

Only after that feasibility packet passes should a **separate predictive
registration** compare a removable single extractor with these controls:

| Proposed arm | Identical information opportunity, increasing feature set |
| --- | --- |
| N | Fixed predecision market-only features on the same statement opportunities; event-conditioned, not an unconditional strategy. |
| A | N plus calendar, target-range/rate change and deterministic policy numbers. No consensus required. |
| B | A plus prior-statement deterministic diff, fixed policy terms/negations and cheap numeric/text features. |
| C, optional | B plus one bounded source-spanned structured language extractor, verified deterministically; no debate, external browsing or authority to trade. |

Use a common, predeclared decision time after full receipt (not an assumed exact
14:00 availability), with a frozen processing deadline and a market-feature
cutoff shared by arms. Record actual stage timings. A late C abstains and pays
its costs. Define a simple fixed horizon, execution opportunity, eligible quote
conditions, spread/slippage/fees, opportunity denominator and cost allocation
under the later registered evaluator. Avoid choices based on returns observed
during the feasibility pilot; any inspected pilot outcomes are selection data.

The primary later predictive question should be paired C-minus-validation-chosen
best non-LLM **net** return at the common opportunity, with portfolio survival
and exposure-matched checks. Cluster by release/meeting episode; the cross-section
of securities cannot multiply independent announcement counts. Historical LLM
comparisons remain exploratory because weights may contain later information.

**Before either pilot or predictive registration starts:** clear the current
acquisition gate without replacing FMBH/candidate ordering; separately authorize
this event study; qualify Q-FED, relevant rights, receipt capture, instrument and
market data; freeze exact future start/end rules, stage deadline/clock threshold,
success/failure criteria, costs/budget, software and the trial ledger. Predictive
registration additionally needs train/validation/untouched-test periods, fixed
horizon and execution/cost model, selection/tuning budget, minimum detectable
effect and power/sample-size calculation using permissible calibration data.
Eight meetings cannot substitute for that calculation. If prospective capture
has not begun, dates must be newly registered before collection; never reuse
elapsed dates in ADR 001.

These are **unregistered proposals only**. Missing registration parameters are
explicit future gates, not defaults the agent may choose while evaluating.
Neither feasibility capture, model calls nor performance access occurred here.
