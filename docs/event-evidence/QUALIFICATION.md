## Common acceptance packet required later

The later source owner/reviewer must freeze a qualification record per
publisher/distributor/dataset/channel/edition/period, including:

- Field dictionary and clocks with native precision, timezone, uncertainty,
  source version semantics, embargo/release distinctions and documented nulls.
  Establish representative original, update, revision, retraction, duplicate,
  delayed-publication, no-change and outage cases relevant to that family.
- Complete event inventory in the declared scope, with independent calendar or
  official document reconciliation, missing/failed/withdrawn/late counts, source
  outages, pagination and historical coverage limits. Define denominators and
  missingness handling before any outcomes. API reachability is not completeness.
- Original bytes and attachments bound to stable IDs, hashes, version links and
  source spans. Demonstrate whether an old query returns original or latest text.
  Capture logs prove actual receipt only for their observer/channel; no recreated
  historical receipt based on today's download. Test as-of reconstruction against
  independently known versions, and show later inputs do not change past views.
- Historical entity/class/exposure proof, including linkage valid and knowledge
  times, ambiguity handling and a frozen crosswalk. No current-profile fallback.
- Written rights assessment covering local/private raw retention, immutable
  version copies, backups, derived features, commercial/personal research scope,
  permitted external AI processing, redistribution, publication, audit access,
  termination and reproducibility. Unknown rights quarantine dependent work;
  hashes do not substitute for missing authorized bytes.
- Actual provider/delivery/data costs, lawful consensus entitlements and all
  restrictions that affect an eventual cost ledger. Do not procure or authenticate
  on this issue. Qualification of metadata/rights alone does not run an experiment.
